# Expense Tracker

A simple React app for tracking personal expenses — add, delete, and see a running total of your spending.

## Features

- Add an expense with a description, category, and amount
- Delete individual expenses
- Automatically calculates and displays the total amount spent
- Responsive layout for mobile and desktop

## Built With

- React
- Vite
- CSS

## Getting Started

1. Clone the repository
```bash
   git clone https://github.com/Mojoyinola03/expense-tracker.git
```

2. Move into the project folder
```bash
   cd expense-tracker
```

3. Install dependencies
```bash
   npm install
```

4. Start the development server
```bash
   npm run dev
```

5. Open the local URL shown in your terminal (usually `http://localhost:5173`)
